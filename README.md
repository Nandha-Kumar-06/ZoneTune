# ZoneTune 📍🔊

ZoneTune is an Android application that automatically manages device volume based on user-defined geographical zones.

## 🚀 Features

- 📍 Location-based volume automation
- 🗺️ Create and manage geographical zones
- 🔊 Automatically change volume when entering or leaving a zone
- 📊 Activity and event logs
- ⚙️ Customizable settings
- 🔐 Google authentication
- 📱 Modern Android UI

## 🛠️ Tech Stack

- Kotlin
- Android Studio
- Jetpack Compose
- Room Database
- Android Geofencing API
- Google Maps
- MVVM Architecture

## 🏗️ Architecture

ZoneTune follows a modular Android architecture separating:

- UI
- ViewModels
- Repository layer
- Database
- Geofencing
- Background services

## 🎯 Purpose

ZoneTune was developed to automate device audio settings based on the user's location, reducing the need to manually change volume profiles.
